# Instruções do WebFusion

Aplicam-se a todo `src/webfusion/`. Após as
[regras gerais](../../docs/agents/INSTRUCTIONS.md), leia:

1. [ARCHITECTURE.md](.instructions/ARCHITECTURE.md): responsabilidades e contratos.
2. [ENVIRONMENT.md](.instructions/ENVIRONMENT.md): container e execução autorizada.
3. O README do módulo envolvido.

Mudanças que afetem o summary também seguem o
[contrato compartilhado](../../docs/architecture/SUMMARY.md). Integrações de
métricas seguem [METRICAS_OPERACIONAIS.md](../../docs/architecture/METRICAS_OPERACIONAIS.md).
